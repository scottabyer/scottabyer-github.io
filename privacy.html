Privacy policy for rclone-vault

Last updated: November 6, 2026

Who this covers

rclone-vault is a personal tool used only by its owner, Scott Byer, with his own Google account. It has no other users.

What Google data the tool accesses

The tool requests the Google Drive drive.file scope. This allows it to create, update and delete only the files and folders that the tool itself created in the owner's Google Drive. It cannot read, list or change any other files in Google Drive, and it does not access email, contacts, calendar or any other Google data.

How the data is used

The tool uploads the owner's own notes from his computer to a folder in his own Google Drive and keeps that folder up to date. That is its only purpose.

Storage and sharing

The Google sign-in token is stored only on the owner's computer. The tool does not send data to any server other than Google's, does not collect analytics, does not sell or share data with anyone, and does not use data for advertising or to train AI models.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops the tool. Files it already created stay in Google Drive until deleted there.
