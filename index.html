rclone-vault

rclone-vault is a personal, single-user tool run by Scott Byer. It is not a public product and is not offered to anyone else.

It runs on one computer owned by Scott Byer and copies his own notes, one way, into a folder in his own Google Drive account, so he can read them from his phone. It uses the open-source rclone program with the Google Drive API.

The tool requests only the drive.file permission, which limits it to files and folders the tool itself creates. It cannot see or change anything else in Google Drive.
